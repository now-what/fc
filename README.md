# francescocolombo.me

Personal website of Francesco Colombo.

**Live site:** https://www.francescocolombo.me

A lightweight, multilingual personal website built with plain HTML, CSS and vanilla JavaScript.

## Features

- English, Italian and French versions.
- Responsive layout.
- Light and dark themes, respecting system preferences.
- No frameworks, build tools or external dependencies.
- No analytics, tracking or third-party fonts.

## Project structure

- `index.html` - English homepage
- `it/` - Italian version
- `fr/` - French version
- `404.html` - Custom error page
- `assets/` - Stylesheets, JavaScript and images

## Deployment

Hosted on GitHub Pages with a custom domain.
